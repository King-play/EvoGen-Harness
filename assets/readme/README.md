# README presentation assets

The overview and qualitative examples reproduce the authors' original paper figures, not newly generated experimental images:

- `overview.png`: Figure 1, frozen-generator execution and TRACE.
- `progressive-repair.jpg`: Figure 4, progressive visual repair.
- `responsibility-examples.jpg`: Figure 6, responsibility-specific examples.
- `cross-generator.jpg`: Figure 7, separately adapted frozen generators.

The light/dark EvoGen SVGs are the previously prepared team identity assets. They use vector paths and require no bundled font files. Static badges indicate links/license/reference runtime, not fabricated CI status.

All README media are local so a merged repository does not depend on a particular `docs/` site revision or external image CDN. See the [paper](https://arxiv.org/abs/2610.00383) and [third-party notices](../../THIRD_PARTY_NOTICES.md).
